# JC Dartz Web Games

Bar-style dart games for a Granboard, or JCDartz in Granboard mode, over Bluetooth.
Runs in Chrome on Android tablets and phones, and on Chromebooks and PCs.
Play it at https://tejanoiniowa.github.io/jc-dartz-web-games/

Phase 1, first slice: 01 games (301/501/701/901), teams, best of 3/5, computer players,
players and stats, settings, board lights, and offline play.

Voice clips: put MP3 files in `audio/` with these names. Any clip that's missing
is spoken by the tablet's own voice instead.
